# 優淼會議紀錄版面規格

適用於 PDF，也可轉成 Word 的等效格式。使用 A4 直向，左右留白約15毫米、上下約14毫米；正文10至11點，行距約16至17點。內容較少時自然留白，無需把範例七頁固定套用。

## 配色

| 用途 | 顏色 |
| --- | --- |
| 主色 深青綠 | #136C70 |
| 正文及標題 深墨綠 | #18383D |
| 章節色塊／淺色列 | #EAF4F3 |
| 表格交替列 淺灰 | #F3F5F6 |
| 金句交替卡片 淺米金 | #F7EEDB |
| 深色表頭文字 | #FFFFFF |

色彩用於資訊層級：頁頂細長青綠色帶、章節淺青綠色塊、深色表頭和交替淺色列。避免裝飾插畫及過多配色。標題下方用留白，不加橫線。若輸出技能預設要求黑色標題，此處為用戶確認的特定版面參考，依此配色。

## 層級與表格

- 主標題約21點；章節標題約14點，置於淺青綠色塊；部門小標題約11.5至12點。
- 首頁基本資料用雙欄表：「日期」「時間及地點」「與會者」「列席者」「缺席者」。左欄約16%，右欄約84%；標籤淺青綠、內容淺灰。
- 部門匯報用短段落及小標題，保持固定議程。重要財務數字可在有足夠數據時用表格，不能新增推算結餘。
- 活動分工有多項時加「統籌項目／負責人及安排」表。需要時保留活動說明及分工摘要，避免無意義重複。
- 跟進事項必用三欄表：「負責人／跟進內容／時間」，欄寬约24%／56%／20%。表頭深青綠、白字；正文交替淺青綠及淺灰。
- 表格儲存格約9.5至10點字，行距15點，四邊留約8至10點空間。英文姓名保持完整，必要時在人名前換行。跨頁表格重複表頭，避免一列被拆得難以閱讀。
- 頁腳列分會名稱、會議日期及頁碼；章節標題要與下一段保持同頁。不要讓色塊、標題或單獨表头留在頁末。

## 金句精選

來源附有金句精選時，放在正文、跟進及待核實事項之後的獨立章節。通常另起一頁，但不強制固定頁數。

每段金句用一張卡片：編號及來源標籤在上，完整引文在下。引文約12點、行距21點；卡片交替淺青綠與淺米金，左側加青綠色直線，內留白約12至15點。

把簡體轉為繁體，可將「系」等明確廣東話轉錄用字改為「係」，但不潤飾成新的金句。原文有疑似誤詞時保留並待核實，或清楚標示經確認的改字。未有發言者署名就不加人名。若把內容改寫成摘要，需以「重點摘要」標示，不能仍當作直接引文。
